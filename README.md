# SWYNEX-Exploratory-Data-Analysis


## Objective

The objective of this task is to perform Exploratory Data Analysis
on the prepared student performance dataset.

## Analysis Performed

- Dataset overview
- Descriptive statistics
- Gender-wise analysis
- Distribution of Students by Age
- Distribution of Study Time
- Distribution of Previous Failures
- Students Absences
- Data visualizations

## Visualizations

1. Number of Students by Gender
2. Students Age Distribution
3. Study Time Distribution
4. Distribution of Previous Failures
5. Distribution of Student Absences
6. Pass/Fail Distribution

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Findings

The analysis identified patterns in student performance and
relationships between different academic scores and background
factors.

## Conclusion

EDA provides useful insights that can support further analysis
and future machine learning modelling.
